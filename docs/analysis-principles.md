# 分析口径

## 数据层级

1. **API 原始事实**：牌型、最终定约、得分、Datum、xIMP、IMP、VP、Butler 等。
2. **确定性推导**：HCP 合计、配合张数、Datum 差、IMP 换算、两室累计。
3. **人工补录**：用户提供的叫牌、首攻和打法。
4. **启发式分析**：复盘优先级、可能的牺牲叫、摆幅分类和学习问题。

报告必须让读者能区分这些层级。启发式结论不是官方判罚，也不是唯一正确桥牌判断。

## 单副牌

- DD 和 Par 是双明手基准，不能证明实战必须叫到某个定约。
- 没有叫牌过程时，只分析最终定约和全场分布能够支持的内容。
- “成局高度”不等于“本方尝试完成成局”；对方有可成局、己方被加倍宕墩且代价更低时，应优先识别牺牲叫。
- phantom、空白和调整占位不进入落点、成局率和技术比例。
- 两室是两个独立结果，统计时分别计数；完全相同可在展示时合并一行。

## 比赛和赛事

- 具体 match 摆幅优先使用官方 `impNS / impEW`，派生 IMP 只用于校验或字段缺失时回退。
- xIMP 衡量相对全场 Datum 的表现，不能替代一场两室比赛的官方 IMP。
- IMP.Q 和平均对手分只展示官方字段，不猜测服务端公式。
- Butler、AOB、修正 Butler 使用官方字段；比较牌手时必须同时看副数。
- 逐副累计与官方最终比分不一致时，报告明确提示并以官方比分为准。

## 可解释性边界

CCBA 部分结果没有完整叫牌、首攻或逐墩打法。缺失这些信息时，报告不会把结果差异武断归因于某次叫牌或某张首攻；需要精确复盘时使用 `--notes` 补录实际过程。
